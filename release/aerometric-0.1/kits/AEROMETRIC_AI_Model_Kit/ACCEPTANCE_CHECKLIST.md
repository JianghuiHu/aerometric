# Acceptance checklist

- [ ] GLB parses and contains visible geometry.
- [ ] Physical dimensions match the source asset.
- [ ] Profile JSON is valid and every role resolves.
- [ ] Declared rotor nodes are unique and rotate about correct pivots.
- [ ] Declared gimbal axes work without rotating the body.
- [ ] Editable colors and visibility groups are independent.
- [ ] Status-light diffusers retain emissive properties.
- [ ] Hidden objects are absent after current-state export.
- [ ] Scene systems are absent from the model GLB.
- [ ] Exported GLB was re-imported and checked.
- [ ] Model, texture, and reference-image licenses are documented.
