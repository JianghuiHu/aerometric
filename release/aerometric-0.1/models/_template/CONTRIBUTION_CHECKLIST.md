# Model contribution checklist

- [ ] `model.glb` opens and contains visible geometry.
- [ ] `model.aerometric.json` maps names that exist in the GLB.
- [ ] `preview.webp` represents the submitted model.
- [ ] `README.md` identifies author, type, compatibility, and tested capabilities.
- [ ] `LICENSE` grants redistribution rights for the model and textures.
- [ ] Four declared rotor roles resolve to unique objects.
- [ ] Rotor pivots and gimbal hierarchy were tested in motion.
- [ ] `aerometric-validator models/<model-id>` passes.
- [ ] The contributor created the assets or has permission to redistribute them.
