# AEROMETRIC v0.1.1 Release Notes

English | [简体中文](../zh-CN/release-notes-0.1.1.md)

**Product presentation, official V3 model, performance update, and bilingual repository experience.**

## Highlights

- Quadrotor V3 is the default official full-feature model and is released under CC0-1.0.
- Reference Drone 01 remains the lightweight CC0 validation model.
- The repository now presents Studio, Model Standard, AI Skill, Blender Creator Kit, and Model Library as one product workflow.
- English and Simplified Chinese user documentation is available.
- The public Community Model Library lists both validated official models.
- The recorded V3 Bloom baseline improved from approximately 12.3 FPS to 56.8 FPS.
- Source tests, license gates, model validators, and production build remain required for publication.

This page describes the v0.1.1 candidate. The existing v0.1.0 GitHub Release is not rewritten.
