# AEROMETRIC v0.1.1 发布说明

[English](../en/release-notes-0.1.1.md) | 简体中文

**产品介绍、官方 V3 模型、性能优化与中英文 GitHub 体验完善。**

## 重点变化

- Quadrotor V3 成为默认官方完整功能模型，并以 CC0-1.0 发布。
- Reference Drone 01 继续作为轻量 CC0 验证模型。
- 仓库以一套统一流程呈现 Studio、Model Standard、AI Skill、Blender Creator Kit 和 Model Library。
- 增加 English 与简体中文用户文档。
- 公开 Community Model Library 收录两款已验证官方模型。
- 记录的 V3 Bloom 本地基线由约 12.3 FPS 提升至 56.8 FPS。
- 公开发布仍需通过源码测试、授权门禁、模型 Validator 和 Production Build。

本页描述 v0.1.1 候选版本；不会重写既有 v0.1.0 GitHub Release。
