# AEROMETRIC Reference Drone 01

Official Reference Model

The asset license in [LICENSE](LICENSE) covers `model.glb`, `preview.webp`, and model-specific `model.aerometric.json` metadata. Attribution is not required by CC0. Repository code, Skill, Schema, Validator, and the Blender generator remain under the repository's MIT license.

Geometry, materials, and the preview render are generated by the repository Blender script at `../../blender/build_reference_drone_01.py`. The script uses Blender primitives and hand-authored mesh profiles; it imports no third-party models, images, fonts, or textures. The model is not derived from Quadrotor V3.

The package provides `model.glb`, `model.aerometric.json`, and `preview.webp`. The GLB has a single `DRONE_ROOT`, semantic glTF extras, separately addressable body/top cover, four arms, motors and rotors, landing gear, two-axis gimbal, camera, and six small status-light meshes. Rotor pivots are at their motor centers. The Profile declares the same roles for applications that do not consume extras.

The source asset has 60 meshes, 2,928 triangles, 12 named materials, and no texture files. Runtime effects such as the expanding ground status field, rain, sky, camera, and lighting are Studio scene features and are intentionally absent from this GLB.

Verified compatibility:

- Level 1 DroneProfile and Level 2 glTF extras
- Editable colors and visibility groups
- Four independent rotor controls with motor-centered pivots
- Gimbal yaw and pitch, camera, and six status lights
- Status field and environment compatibility in Studio
- Current-state GLB export and re-import; PNG and JPG export

To regenerate with Blender 5.2, run `blender --background --factory-startup --python release/aerometric-0.1/blender/build_reference_drone_01.py -- release/aerometric-0.1/models/aerometric-reference-drone-01` from the repository root. Validate with `node release/aerometric-0.1/validator/src/cli.mjs release/aerometric-0.1/models/aerometric-reference-drone-01`.
